# Magic Moments

Moments users emotionally remember are the product moat.

## 1. "The co-director noticed the emotional callback"
- Trigger: motif appears in later scene and matches earlier emotional context.
- User emotion: seen, understood, artistically validated.
- Required signals: motif state + memory references + scene linkage.
- Difficulty: medium.
- Demo value: very high.

## 2. "The studio remembered a visual motif from Act 1"
- Trigger: later sequence includes callback with identity consistency.
- User emotion: trust in creative memory.
- Required signals: motif persistence + memory records.
- Difficulty: medium.
- Demo value: very high.

## 3. "The system warned the ending lost emotional tension"
- Trigger: ending impact drops below expected arc trajectory.
- User emotion: protected from avoidable narrative failure.
- Required signals: dread curve + ending impact + pacing trend.
- Difficulty: low-medium.
- Demo value: high.

## 4. "Screening explained why the cut worked"
- Trigger: approved/ready gate with coherent advisory rationale.
- User emotion: confidence and clarity.
- Required signals: decision gate + continuity/style summaries + review status.
- Difficulty: low.
- Demo value: very high.

## 5. "Production felt like a real film pipeline"
- Trigger: queue, provider status, ready-to-screen guidance align in one view.
- User emotion: professional legitimacy.
- Required signals: render jobs + gate + CTA flow.
- Difficulty: low.
- Demo value: high.

## 6. "Previs told me what the shot is trying to become"
- Trigger: shot intent + emotional beat + confidence read.
- User emotion: creative orientation.
- Required signals: scene intent + continuity/style/memory evidence.
- Difficulty: low.
- Demo value: high.

## 7. "Study Room told me exactly where to go next"
- Trigger: context-aware next-room recommendation.
- User emotion: momentum and reduced cognitive load.
- Required signals: gate status + evidence counts + render/review state.
- Difficulty: low.
- Demo value: high.

## 8. "It explained why this shot matters"
- Trigger: user sees `Why this shot matters` in Previs and Screening for the selected shot/cut.
- User emotion: creative trust; the system feels like a collaborator, not a tracker.
- Required signals: memory records, continuity/style drift, decision gate state, director signature, review/package readiness.
- Difficulty: low.
- Demo value: very high.

## 9. "I can steer the interpretation without changing the cut"
- Trigger: user switches Revision Emphasis between `Emotional Residue` and `Structural Clarity`.
- User emotion: authorship and collaboration; the Studio responds to creative framing, not just system state.
- Required signals: revision comparison context, continuity/style drift, memory records, gate state.
- Difficulty: low.
- Demo value: very high.

## Taste Memory Bridge Note
- This moment is intentionally non-persistent today.
- It establishes the interaction pattern that can later inform taste memory:
  - preference selections
  - accepted tradeoffs
  - ignored disagreements
  - revision-choice behavior
- Do not add scoring, persistence, or auto-rewrite behavior in this phase.
