│ 1. SETUP                                                                   │
└────────────────────────────────────────────────────────────────────────────┘

  export GROQ_API_KEY="your_groq_api_key_here"

┌────────────────────────────────────────────────────────────────────────────┐
│ 2. EXTRACT FRAMES FROM VIDEO                                              │
└────────────────────────────────────────────────────────────────────────────┘

  Using ffmpeg to extract at 10%, 50%, 90%:

  ffmpeg -ss 1.0 -i video.mp4 -frames:v 1 -q:v 2 frame_10pct.jpg
  ffmpeg -ss 5.0 -i video.mp4 -frames:v 1 -q:v 2 frame_50pct.jpg
  ffmpeg -ss 9.0 -i video.mp4 -frames:v 1 -q:v 2 frame_90pct.jpg

  (Adjust -ss times based on your video duration)

┌────────────────────────────────────────────────────────────────────────────┐
│ 3. RUN MANUAL TEST                                                         │
└────────────────────────────────────────────────────────────────────────────┘

  cd studio-backend

  python manual_adherence_check.py \
      --frames frame_10pct.jpg frame_50pct.jpg frame_90pct.jpg \
      --character "weathered hand, pale skin" \
      --action "reaching toward artifact" \
      --camera "extreme closeup" \
      --lighting "dim candlelight" \
      --environment "stone pedestal"
