PREREQUISITES:
1. Set GROQ_API_KEY environment variable
2. Have 3 frame images extracted from a video (10%, 50%, 90% positions)

RUN THE SCRIPT:

  cd studio-backend
  
  python manual_adherence_check.py \
      --frames frame1.jpg frame2.jpg frame3.jpg \
      --character "weathered hand, pale skin, visible veins" \
      --action "reaching slowly toward ancient artifact" \
      --camera "extreme closeup, shallow focus" \
      --lighting "dim candlelight, warm amber glow" \

IMPORTANT NOTES
═══════════════════════════════════════════════════════════════════════════════

⚠️  GROQ IS A PLACEHOLDER:
    The code includes an explicit comment that Groq's llama-3.2-90b-vision-preview
    is NOT intended as the permanent choice. For production fine-grained consistency
    judgments (e.g., "is this the same weathered hand as attempt 1"), swap in
    GPT-4o or Claude via ADHERENCE_VISION_PROVIDER environment variable.

🔧 CONFIGURATION:
    Vision provider is configurable via environment variables:
    
    export ADHERENCE_VISION_PROVIDER="groq"   # or "openai", "anthropic"
    export ADHERENCE_VISION_MODEL="llama-3.2-90b-vision-preview"
    
    Note: Only Groq is currently implemented in the code.

📝 CODE COMMENT LOCATION:
    The placeholder note is in adherence_service.py at line ~96:
    
    # NOTE: Using Groq's llama-3.2-90b-vision-preview as placeholder.
