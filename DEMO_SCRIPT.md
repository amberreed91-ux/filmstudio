# Cinematic Demo Script (3-5 Minutes)

## 1) Opening Hook (20-30s)
"Most AI video tools can generate clips. Very few can direct a film. Studio is built for the second problem."

"This is not a prompt box. It is a cinematic operating system that carries creative intent from first evidence to final package."

## 2) The Problem (25-35s)
"Today, teams jump between disconnected tools: one for generation, one for notes, one for review, one for exports. Context gets lost, and every revision forgets what mattered emotionally in the previous cut."

"You can make a clip, but you cannot sustain a film identity."

## 3) Why Studio Is Different (20-30s)
"Studio is room-based and memory-aware. It keeps continuity between creative planning, production, review, and operational handoff."

"Instead of asking ‘can we generate?’, it asks ‘does this still feel like the same film?’"

## 4) Room-by-Room Narrative (90-120s)

### Lobby
"One click launches a deterministic seeded project so the full pipeline is demo-stable."

### Study Room
"Study surfaces evidence, memory context, and co-director guidance. This is where the system shows it understands the project before giving advice."

### Previs
"Previs translates intent into shot direction. We get cinematic framing plus practical next moves, not vague AI suggestions."

### Production Board
"Production turns intent into execution: render queue, readiness, and handoff clarity."

### Screening Room
"Screening is where creative intelligence becomes visible: why the cut works, where tension slips, and what to do next."

### Crew Ops
"Crew Ops is the live pulse board: which departments are ready, which need attention, and how to keep the pipeline coherent."

## 5) Emotional Intelligence Reveal (30-40s)
"Now the key difference: Studio doesn’t just track assets. It explains creative significance in plain cinematic language."

"Notice the line: **Why this shot matters.** That is the shift from workflow tracker to creative collaborator."

## 6) Creative Disagreement Reveal (25-35s)
"Great collaborators don’t always agree. Studio can selectively push back when a cleaner revision weakens emotional carryover."

"It is restrained: short, contextual, and never blocking. No score spam, no fake certainty."

## 7) Taste Memory Reveal (25-35s)
"In Screening, the Revision Emphasis toggle introduces the first creative preference axis: Emotional Residue vs Structural Clarity."

"Studio now shows an **Emerging Taste Read** for this session only. It can preview preference without pretending permanence or storing a profile yet."

## 8) Closing Line (10-15s)
"Studio is not another AI video wrapper. It is a cinematic operating system that keeps creative memory alive from first evidence to final cut."
