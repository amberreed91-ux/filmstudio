KEY FEATURES
================================================================================

1. MULTI-FRAME SCORING
   - Extracts frames at 10%, 50%, 90% of shot duration
   - Detects temporal drift across the shot
   - Scores 5 dimensions per frame with evidence collection

2. WEIGHTED DIMENSION SCORING
   - character_state: 0.25 (highest priority)
   - environment_persistence: 0.25 (highest priority)
   - action: 0.20
   - camera: 0.15
   - lighting: 0.15

3. VERDICT THRESHOLDS
   - pass: adherence_score ≥ 80
   - correctable: 50 ≤ adherence_score < 80 AND attempt_n < 3
   - manual_review: adherence_score < 50 OR attempt_n ≥ 3

4. CORRECTIVE DIFF GENERATOR
   - Small Groq call (cheap, text-only)
   - Only sees expected/observed text, not video
   - Three operation types: replace, strengthen, prepend_emphasis
   - Tracks character budget with char_delta

5. DETERMINISTIC DIFF APPLICATION
   - Pure function (no LLM call)
   - Respects 512-char Runway limit
   - Smart overflow protection:
     * Pre-compression if already over budget
     * Per-op compression if operation causes overflow
     * Final safety compression if still over
     * Compression priority: lighting < camera < environment < action < character
     * NEVER compresses the slot being corrected (it's failing for a reason)

6. VISION MODEL CONFIGURATION
   - NOT hardcoded to Groq
   - Configurable via ADHERENCE_VISION_PROVIDER env var
   - Defaults to "openai" / "gpt-4o"
   - Code comment documents why stronger model needed:
     "Fine-grained consistency judgments (e.g., 'is this the same weathered
      hand as attempt 1') require stronger vision models than Groq's default.
      This is worth one non-Groq API call per render given how much the 
      system depends on scoring accuracy."
