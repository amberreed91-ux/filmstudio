IMPLEMENTATION NOTES
====================

- Seed values: random integer 1–999,999
- Storage: persisted in database (previs_images table)
- Scope: per-scene (each scene has own seed)
- Pollinations URL format: https://image.pollinations.ai/prompt/{encoded}?width=768&height=432&nologo=true&seed={seed}
- Manual control: user must click lock button to enable seed reuse
- Auto-reuse: once locked, seed automatically reused on regenerations
- Visual indicators: lock icon shows state (green=locked, gray=unlocked)
